# PetLand 3.0.0-rc.1 — notas para revisão

Candidata de portfólio local. Versões npm/OpenAPI `3.0.0-rc.1`; distribuição Python `3.0.0rc1` (forma PEP 440 equivalente). Schema `0006_hardening`. Base integrada P07 `3dde06b133a53a1b704eb6f5113a01a85d5a741e`; histórico antigo preservado em `legacy/petland-2.0-2024-11-24`.

## O que entrega

Sessões/CSRF e três perfis, cadastro próprio/assistido de tutores/pets, catálogo por porte, capacidade configurável, confirmação de reserva, cancelamento/reagendamento comunicados, execução de atendimento, notas privadas/resumo público, histórico, indicadores e auditoria. Exclusões de intervalos, versões, snapshots e idempotência conservam integridade sob concorrência.

Staging Nginx/HTTPS, PostgreSQL TLS e SMTP STARTTLS, seed/reset isolados, backups autenticados e restauração reconciliada em banco novo. Case com capturas históricas identificadas, vídeo de três jornadas reais, legendas/transcrição, diagramas, dicionário e relatório de qualidade.

[README](../../README.md), [case](../case/README.md), [operação](../runbooks/operations-recovery.md), [qualidade](quality-report.md). Dependências congeladas; `python scripts/dev.py check`, `e2e`, `rehearse` e `python scripts/release.py check`. Pipeline do commit da candidata nos checks do PR P08.

Segredos, bancos, dump, CA/chaves, venvs e dependências instaladas não acompanham o pacote. Ferramenta verifica consistência, não concede aceite. [Procedimento e rollback](../runbooks/release.md).

## Limites de promoção

Aceite final de produto e validação humana com leitor de tela pendentes. D10 conserva publicação/provedor/e-mail externo e backup fora do host adiados. D08/D12 dispensam importação histórica. Sem dados reais, multiempresa ou pagamentos. Não há tag `v3.0.0`, release estável/publicação ou promoção automática nesta entrega; essas ações vêm depois do aceite concreto e decisão de ambiente.
